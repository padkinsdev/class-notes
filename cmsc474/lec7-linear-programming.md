# Linear Programming

## Introduction
- Linear programming is a technique to maximize or minimize a linear objective, and is subject to linear equalities and inequalities
- Steps:
    - Determine the decision variables
    - Determine the objective function
    - Determine the constraints
- A feasible solution satisfies all of the constraints
- An optimal solution is the best feasible solution
- Decision variables are quantities you can control to improve your objective which should completely describe the set of decisions to be made
- Constraints are lamitiations on the values of the decision variables
- An objective function is a value measure used to rank alternatives
- If you have an NP solver that can solve maximizations, then it can also be used to solve minimizations
- A mathematical program is a linear program if the objective is a linear function and the constraints are linear equalities or inequalities
- An integer program is a linear program plus constraints that some or all of the variables are integer-valued
