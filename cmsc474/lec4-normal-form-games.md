# Normal Form Games

## Games in normal form
- A (finite, n-person) normal-form game includes the following:
    - An ordered set N=(1,2,3,...,n) of **agents** or **players**
    - Each agent has a finite set $A_i$ of possible actions
        - An action profile is an n-tupel $a = (a_1,a_2,...,a_n)$ where $a_1 \in A_1, a_2 \in A_2,...,A_n$
        - The set of all possible action profiles is $A=A_1 \times ... \times A_n$
    - Each agent i has a real-valued *utility* or *payoff* function $u_i (a_1,...,a_n) =$ i's payoff if the action profile is $(a_1,...,a_n)$
- Most other game representations can be reduced to normal form
- Usually represented by an n-dimensional **payoff** (or **utility**) matrix
    - For each action profile, shows the utilities of all the agents
