# The Genetic Code

# Background
- DNA consists of pairs of nucleobases attached to a sugar phosphate backbone
- Between RNA and DNA, the nucleotides are adenine, thymine, guanine, cytosine, and uracil, with uracil replacing thymine in RNA
- The human genome is 3 billion base pairs long
- The sugar in RNA is ribose, as opposed to the deoxyribose in DNA. RNA is also single stranded
- DNA is wrapped around histones, coiled into strands, and folded into chromosomes
- DNA is first transcribed into messenger RNA (mRNA), then translated into proteins
- Groups of 3 base pairs (codons) in mRNA correspond to an amino acid, and the amino acids are chained together to make proteins by ribosomes
- Multiple base pair triplets code for a stop codon, whereas only one triplet codes for a start codon
